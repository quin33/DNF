# 修仙世界观设定 ·《问道》· 简版

> 用途：基于现有深渊酒馆复刻框架制作的修仙游戏世界观。总字数约 3500 字。

## 一、世界背景

天地初开，灵气充盈。万年前一场「灵潮崩坏」撕裂天穹，九州灵脉断裂，人间灵气日渐稀薄，凡人再难凭自身感悟大道。残存的灵气汇聚成九座「洞天福地」，修仙者聚居于此，凡人则散落于灵气枯竭的边荒。

洞天之间由「灵墟」相连——那是上古仙魔大战留下的破碎空间，既藏机缘，亦伏凶险。如今的修仙界没有统一王朝，只有宗门、世家与散修在灵墟边缘争夺资源，有人问道长生，有人求的不过是多活一纪。

玩家扮演一名初入仙途的修士，从一座边陲「仙坊」出发，招募同道、组队进入灵墟探险。

## 二、修炼境界（等级体系）

| 境界 | 描述 | 对应原系统等级 |
|---|---|---|
| 境界 | 阶段划分 | 对应等级 |
|---|---|---|
| 练气 | 一层～十层（每层细分） | Lv.1–10 |
| 筑基 | 前期 / 中期 / 后期 | Lv.11–13 |
| 金丹 | 前期 / 中期 / 后期 | Lv.14–16 |
| 元婴 | 前期 / 中期 / 后期 | Lv.17–19 |
| 化神及以后 | 后续版本开放 | — |

突破需「感悟 + 丹药 + 机缘」，机缘主要来自灵墟探险。练气期每层突破靠灵气积累（共十层）；筑基起每次突破需渡小劫，境界越高劫数越重。

## 三、修士属性（沿用四维，语义替换）

| 属性 | 原系统 | 修仙语义 |
|---|---|---|
| 力量 | strength | **体魄**：气血、体修强度 |
| 敏捷 | agility | **身法**：遁速、闪避 |
| 智力 | intelligence | **神识**：感知、推演、炼器炼丹 |
| 幸运 | luck | **气运**：奇遇概率、避劫 |

额外维度：**灵根**（决定修炼方向）与**心境**（对应原「性格」，影响组队行为）。

## 四、装备道具体系（探险日志的输入来源）

按稀有度：凡品→宝器→法宝→仙器（对应 common/rare/epic/legendary）。

**法宝（武器/装备）**：
- 剑类：青霜剑、噬魂刃、太乙拂尘、离火神幡
- 防具：天蚕宝衣、玄武甲、紫绶仙衣
- 特殊：山河扇（困敌）、镇魂铃（驱鬼）、遁地梭（逃跑）

**丹药（消耗品）**：聚气丹、筑基丹、破境丹、续命丹、暴血丹、清心丹

**符箓（消耗品）**：火球符、隐身符、传音符、遁地符、雷暴符

**材料（采集物）**：灵草、妖兽内丹、矿晶、阵法残片、上古遗物

**杂物**：灵石（货币）、灵茶、兽皮、功法残卷、神秘宝箱

## 五、灵墟（副本地图）

| 灵墟 | 境界需求 | 特色 |
|---|---|---|
| 枯骨林 | 炼气 | 低阶妖兽、亡魂出没 |
| 迷雾泽 | 炼气–筑基 | 瘴气、毒虫、隐匿洞府 |
| 赤炎谷 | 筑基 | 火属性灵植、岩浆妖物 |
| 万剑冢 | 筑基–金丹 | 上古剑修遗物、剑灵试炼 |
| 幽冥渊 | 金丹 | 鬼修巢穴、阴煞之气 |
| 雷音山 | 金丹–元婴 | 天雷淬体、雷系机缘 |
| 落仙台 | 元婴+ | 仙人陨落之地，逆天机缘 |

每个灵墟有 **主路线 + 隐藏事件**（对应原「特殊事件」），隐藏事件由队伍携带的特殊物品触发。

## 六、组织与社交

- **仙坊（原酒馆）**：修士聚集地，接取委托、交换情报、招募队友
- **宗门**：可拜入（剑宗/丹宗/符宗/体宗），提供功法与资源
- **散修**：自由职业，无宗门加成但不受约束
- **秘境拍卖行**：拍卖稀有法宝与丹方
- **论道（原聊天）**：修士闲聊，交流探险心得

## 七、探险日志的叙事风格

日志模仿修真小说笔法：探险过程写成「一人一器一境」的短篇志怪，强调**装备道具在关键时刻的运用**——谁祭出了什么法宝、吞服了什么丹药、用符箓化解了什么危机、在何处拾得何物。结局或圆满或惨烈，修士可能陨落（对应原「阵亡」系统）。
