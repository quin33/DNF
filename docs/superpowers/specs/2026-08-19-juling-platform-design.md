# 聚灵台设计

## 目标

在驻地建筑页的藏经阁旁新增“聚灵台”。玩家可在其中进行限时闭关修炼或闭关突破。玩法的时间、资源、经验和突破结果以服务端数据为准，保证刷新页面、关闭浏览器或本地调整系统时间不会改变结算结果。

## 范围

- 新增聚灵台建筑卡片与设施弹窗。
- 新增服务端持久化闭关状态、经验结算、突破结算与同步接口。
- 在角色卡片、冒险者列表和聚灵台弹窗显示修炼中或突破中状态。
- 为关键服务端规则添加自动化测试。

不包含新的丹药、装备、聊天或建筑升级系统。

## 数据模型

每个在线角色新增以下可序列化字段：

```js
cultivation: {
  mode: 'cultivate' | 'breakthrough',
  startedAt: 0,
  endsAt: 0,
  lastSettledAt: 0,
  spentGold: 0
}
breakthroughBonus: 0
```

`cultivation` 不存在时表示未在聚灵台中。`breakthroughBonus` 表示失败累计的下一次突破成功率加成，以小数保存，例如 `0.2` 为 +20%。

## 服务端规则

### 闭关修炼

- 仅空闲角色可开始；修炼中、突破中、组队中或探险中的角色不可开始。
- 玩家选择 1 到 24 的整小时数。
- 启动时一次性扣除 `小时数 * 100` 灵石；灵石不足时拒绝请求。
- 启动后角色状态为 `cultivating`，界面展示为“修炼中”。
- 服务端根据完整的 30 分钟单位结算经验，每单位 +50 经验。即每小时 +100 经验。
- 结算从 `lastSettledAt` 推进，不因重复读取而重复发放。时间未满 30 分钟的余量保留到下一次结算或结束时继续累计。
- 修炼结束后自动结算完整半小时并清除 `cultivation`，角色恢复空闲。
- 玩家可提前出关：服务端先结算已完成的半小时，再清除 `cultivation`；所有已支付灵石不退款。
- 经验沿用现有成长规则：练气一层至九层按既有经验阈值升级；练气十层经验最高为 1000，不通过修炼自动进入筑基。

### 闭关突破

- 仅空闲角色可开始，且必须满足 `level === 10 && exp >= 1000`，即练气十层圆满。
- 未达到条件时，前端突破操作锁定；点击锁定项仅显示“需达到练气十层圆满”，不向服务端提交开始请求。服务端仍重复校验条件。
- 固定持续 2 小时，启动后状态为 `breaking_through`，界面展示为“突破中”。
- 突破期间不可提前出关，且不可创建/加入队伍或进入探险。
- 到期由服务端执行一次判定：成功率为 `min(1, 0.5 + breakthroughBonus)`。
- 成功：角色变为 `level = 11`、`exp = 0`、`character_class = '筑基前期'`，沿用现有升级时的生命增长规则，并清空 `breakthroughBonus`。
- 失败：当前经验变为 0，`breakthroughBonus += 0.1`；加成可多次叠加，并在成功率计算时限制为 100%。
- 到期结算必须具有幂等性，重复请求或多标签页读取不会重复判定、重复升级或重复叠加加成。

## 接口与同步

新增受登录令牌保护的聚灵台角色接口：查询/结算当前状态、开始修炼、提前出关、开始突破。接口接收角色 ID 和现有版本号，沿用角色保存的乐观并发控制。

获取角色资料时也会先尝试补结算。每次角色被聚灵台修改后，服务端更新角色版本并通过已有 `character_updated` WebSocket 消息通知该账号的所有页面刷新角色资料。

## 前端交互

- 建筑页保留现有藏经阁和炼器坊，并在藏经阁旁加入聚灵台。
- 聚灵台弹窗使用两项切换：“闭关修炼”和“闭关突破”。
- 修炼面板提供小时步进控件、灵石总价、开始按钮；不可用状态明确提示原因。
- 突破面板显示前置条件、固定两小时、基础成功率、累计加成与最终成功率。未达标时锁定并提示。
- 闭关进行中，弹窗展示倒计时、角色状态、距离下一次经验结算的时间；修炼显示提前出关按钮，突破不提供退出操作。
- 在任何角色状态更新后重绘建筑页、角色资料和冒险者列表，避免遗留旧状态。

## 互斥规则

聚灵台操作与队伍/副本互斥：正在修炼或突破的角色不能创建或加入队伍，也不能进入探险；已组队或探险中的角色不能开始聚灵台操作。服务端承担最终校验，前端同时禁用对应入口并给出提示。

## 测试

- 修炼启动的时长、角色状态、一次性扣费与灵石不足校验。
- 每 30 分钟结算 50 经验，重复结算不重复增加经验。
- 提前出关无退款，仅结算完整半小时。
- 练气十层经验封顶 1000，其他等级沿用升级阈值。
- 突破的等级/经验前置条件与两小时限制。
- 突破成功升至筑基前期并清空累计加成。
- 突破失败清空经验、叠加 +10%，成功率最高 100%。
- 多次读取与多标签页操作不重复结算。
- 前端锁定未达标的突破操作，并展示相应提示。
