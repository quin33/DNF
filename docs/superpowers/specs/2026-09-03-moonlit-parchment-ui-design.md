# DNF 月光纸笺·轻复古 UI 设计

## 状态

- 设计状态：已获用户确认
- 日期：2026-09-03
- 目标页面：根目录 DNF 游戏前端（`index.html` + `style.css`）

## 目标

将现有 DNF 游戏 UI 重塑为“月光纸笺·轻复古”的月光酒馆风格，同时保留当前的信息架构、业务流程和中间游戏区域白底布局。

视觉目标是让页面具备地下城与勇士式的功能型网游大厅气质：有酒馆、冒险者、桌台、公告和探险手札的世界感，但信息仍然紧凑、清晰、易操作。

## 非目标

- 不修改服务端、数据库、AI 流程或角色数据结构。
- 不重写现有标签页、模态框、日志阅读、在线匹配等业务流程。
- 不引入新的前端框架或外部字体依赖。
- 不使用全页面厚重木纹、浮雕、强纹理或大面积拟物装饰。

## 视觉方向

### 主题基调

- 中间游戏区：暖白羊皮纸，推荐基础色 `#f7f1e5`。
- 页面两侧：继续使用 `pic/天空之城.jpg`，叠加低透明度深蓝遮罩，让中间纸笺成为视觉焦点。
- 复古元素只用于页头、标题条、分区边框、空状态和局部装饰；数据卡片保持平整、紧凑。

### 色彩令牌

```css
--paper-bg: #f7f1e5;
--paper-raised: #fffaf0;
--paper-muted: #eee4d3;
--ink: #2c3440;
--ink-muted: #6f7780;
--moon-blue: #6f879c;
--moon-blue-dark: #31485c;
--copper: #b98545;
--wood: #805a3b;
--danger: #a94b4b;
--success: #557b5d;
```

颜色通过主题变量集中管理，组件不直接散落新的颜色值。浅色主题使用暖白纸笺；深色主题可以继续保留，但应沿用同一组蓝灰、铜金语义，不破坏现有主题切换。

### 字体与层级

- 继续使用本地微软雅黑字体栈，避免外部字体加载失败导致布局变化。
- 酒馆标题、页面标题和分区标题使用更强字重与适度字距，模拟招牌和木牌印字。
- 正文、状态和数据保持现有紧凑尺寸，保证长文本、中文和移动端可读性。
- 重要等级、奖励、状态数值使用铜金或月光蓝突出，不能只依赖颜色表达状态。

## 页面结构

### 页面壳层

- `body` 继续负责《天空之城》全屏背景。
- `.app-content` 继续作为居中的游戏画布，保持最大宽度和暖白羊皮纸底色。
- `.advs1` 作为内容内层，负责统一内边距、内容宽度和横向溢出控制。

### 页头

改造成“月光酒馆招牌”：

- 左侧徽记使用月牙、酒杯或长剑组合的单色徽章。
- 标题和 `S1` 铭牌使用深墨蓝与铜金色。
- 右侧旋转 beacon 改为静态月轮窗或低频呼吸光装饰，减少科技感。
- 仍保留账号操作、主题切换和在线状态入口。

### 公告与提示

- 测试提示使用淡琥珀纸条，左侧保留高辨识度警示标记。
- 酒馆公告使用蓝灰纸笺，上边或左边加入细铜线。
- 纹理和装饰不得降低正文与标题的对比度。

### 标签导航

- 从厚重胶囊按钮调整为平直木牌式菜单。
- 当前项使用铜金色下划线、深墨蓝文字和轻微纸张高亮。
- 导航图标统一为线性图标；主要操作不再使用 Emoji。
- 桌面端横向排列，移动端保留横向滑动与足够触控高度。

### 酒馆大厅与聊天栏

- `tavern-layout` 保持左主区、右聊天栏结构。
- 主区采用“木牌标题 + 铜色小菱形”分区标题。
- 吧台和桌台使用局部木色边框、羊皮纸桌面和虚线铜框空位。
- 已入座角色保持小型角色牌，避免过度装饰影响扫描。
- 聊天栏改为独立留言簿：标题清晰，消息使用短纸条式列表，输入区保持固定尺寸。

### 其他页面

统一复用同一套组件语法：

- 活动页：纸笺公告、奖励榜。
- 建筑页：建筑图鉴卡。
- 我的/冒险者页：角色档案卡。
- 小队页：组队名册和房间桌牌。
- 日志页：探险手札和阅读页。

这些页面只改变局部强调色和标题文案，不重新发明布局。

## 图标策略

- 导航、操作按钮、状态按钮使用统一线性图标（优先使用项目现有图标能力；没有图标库时使用小型内联 SVG）。
- 月牙、酒杯、剑、卷轴、铜扣等仅作为主题装饰或语义图标。
- Emoji 可继续出现在 AI 叙事、角色内容和动态日志文本中，但不作为主要导航或关键操作的唯一视觉提示。
- 图标按钮必须保留 `title` 或可访问名称，不能牺牲键盘和屏幕阅读器可用性。

## 动效与可访问性

- 标签切换：淡入和轻微上移，约 180ms。
- 卡片悬停：边框变亮并上移 1～2px，不改变布局尺寸。
- 月轮装饰：低频呼吸光，不使用持续高速旋转。
- 增加 `prefers-reduced-motion: reduce` 规则，减少非必要动画。
- 保留现有 `:focus-visible` 焦点样式。
- 正文和按钮颜色保持至少 4.5:1 对比度；不能只用红/绿区分成功与危险。

## 响应式规则

- 桌面端：中间纸笺游戏区居中，左右显示背景图。
- 平板端：主内容和聊天栏按比例收窄，避免固定宽度溢出。
- 手机端：聊天栏移动到主内容下方，桌台切换为单列。
- 标签栏允许横向滚动，按钮保持可触控高度。
- 模态框、日志阅读区和在线匹配流程沿用现有移动端行为。
- 在 390px、768px、1024px、1440px 视口下检查文字换行、按钮尺寸、横向滚动和背景裁切。

## 实施边界

### 第一阶段：主题令牌与页面壳层

- 在 `style.css` 中加入纸笺、墨蓝、月光蓝、铜金和木棕变量。
- 调整 `body`、`.app-content`、`.advs1` 的背景、边框和阴影。
- 统一圆角、阴影、间距和过渡时长。

### 第二阶段：公共导航与页头

- 改造 `.advs1-header`、公告区和 `.tabs`。
- 替换主要导航 Emoji，补充图标语义 class。

### 第三阶段：内容面板

- 依次统一酒馆、活动、建筑、冒险者、小队和日志页面。
- 优先保持现有 DOM 结构，只有在图标语义或样式边界需要时才增加 class。

### 第四阶段：验证与微调

- 运行 CSS 结构回归测试和完整 Node 测试集。
- 启动本地服务，在桌面和移动视口检查实际渲染。
- 检查背景图、中间纸笺、标题、导航、聊天栏和模态框是否存在重叠或对比度问题。

## 验收标准

1. 中间游戏区域仍为居中纸笺背景，两侧可见《天空之城》背景。
2. 页头、导航、酒馆桌台和聊天栏具有一致的月光纸笺·轻复古风格。
3. 主要功能入口和标签页行为不变，交互状态清晰。
4. 主要导航和操作不再依赖 Emoji 作为唯一图标。
5. 390px、768px、1024px、1440px 视口无横向溢出和明显文字重叠。
6. `npm test` 全部通过，且新增视觉结构测试覆盖主题令牌与关键容器。

## 备选方案与取舍

- 未选择“深夜版”：氛围更强，但会与已确认的中间白底要求冲突。
- 未选择“冷白月光纸”：更清爽，但复古酒馆辨识度不足。
- 未采用全拟物木纹：会增加视觉噪声、资源体积和维护成本。
